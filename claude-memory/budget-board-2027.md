Design page: https://claude.ai/code/artifact/99a94edd-8c1b-4863-ae56-8999c9c94a06 (copy at `budget/BOARD_2027_AGENT_TEAM.html`).

**Engine:** `weekly-intelligence/scripts/board_2027.py` — `packet` (per-seat markdown from budget_2027.json + budget_actions.json + dashboard-data signals → `budget/board/packet/`), `reconcile` (round-1 papers + round-2 challenges/responses/ops → floor/commit/upside per cell, disputes → `budget/board/reconciliation.{json,md}`), `finalize` (chair decision + votes → `budget/budget_2027_board.json`, `budget/BOARD_2027_DECISION.md`). Mechanical rules: evidence keys not in the packet dropped; chair's number snapped to a number on the table; ops "no" caps commit at stretch; floor ≤ base. `largest_reachable` comes from the chair's decision.json (dated-2027 + capacity-yes cells), capped at the upside.

**Briefs:** `agent-briefs/board/` (00-rules, chair, cco, atm, pos, services, core, growthm, east, cfo, cro, ned, ops, analyst, vote). Rounds: papers (10, parallel, opus) → sceptic challenges (3) + ops capacity (1) → growth responses (7) → reconcile → votes (10) → chair (fable) → finalize → analyst minutes (`budget/BOARD_2027_MINUTES.md`). Working files under `budget/board/round1..round4/` (git-ignored budget/).
