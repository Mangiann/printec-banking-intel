Figure 7.1: Forecast ATM installed base, 2023-2028. Columns 2023-2028, CAGR.
- ATMs: 13,500 / 13,200 / 13,000 / 12,900 / 12,850 / 12,800 — CAGR -1.1%
- Absolute growth: -362 / -300 / -200 / -100 / -50 / -50 — N/A
- Percentage growth: -2.6% / -2.2% / -1.5% / -0.8% / -0.4% / -0.4% — N/A
- ATMs per million people: 1,314 / 1,285 / 1,266 / 1,256 / 1,251 / 1,246 — CAGR -1.1%
- Narrative: installed base forecast to contract over forecast period. Decline expected, ~700 fewer terminals by 2028 vs 2023. Driven by bank branch closures, growth of off-site/independent deployment, increasing cash-out at retail (cashback) and rationalisation. Decline of bank branches in Portugal expected; deployers consolidating/sharing networks. COVID-19 recovery + cash usage stabilising partly offsets. Legislative factors (ATM access provisions, retail cashback rules) limit but do not reverse decline.

### p.545 — Portugal, Section 7.3: Forecast cash withdrawal number and value (Figures 7.4, 7.5)
Figure 7.4: Number of cash withdrawals, 2018-2028 (bars = annual number in millions [left axis 0-600]; line = average number per ATM per month [right axis 0-3,500]). Dark bars 2018-2022 historical, light bars 2023-2028 forecast. Annual number dips ~2020-2021 then partial recovery; gradual decline across forecast.
Figure 7.5: Value of cash withdrawals, 2018-2028 (bars = annual value EUR bn [left axis 0-45]; line = average value per withdrawal EUR [right axis 0-100]). Annual value broadly flat/slightly rising ~EUR 36-40bn; average value per withdrawal rises steadily from ~70 (2018) toward ~95 EUR (2028).
- Narrative: after recovery toward pre-pandemic levels in 2021/2022, total cash withdrawals peaked ~2019; number forecast to decline gradually. Total number of withdrawals forecast at 420 million in 2028 (down from 445m in 2023). Average number of cash withdrawals per ATM per month projected to increase to 2,729 monthly withdrawals in 2028, up from 2,646 in 2022. Total annual value of cash withdrawals projected ~EUR 36-40bn; average value per withdrawal rising.
