### p.661 — Switzerland, Section 7 forecasts (chapter p.35)

### p.662 — Switzerland, cash-withdrawal forecasts (chapter p.36)
**Section 7.3: Forecast ATM cash withdrawal number and value.**
**Figure 7.4: Number of cash withdrawals, 2018-2028** (combo chart). Left axis annual number (million) 0-400; right axis average number 0-4,000 (withdrawals per machine per month). Number of withdrawals declines over the period; average per-machine usage broadly flat.
**Figure 7.5: Value of cash withdrawals, 2018-2028** (combo chart). Left axis annual value CHF bn 0-100; right axis average value CHF 0-500. Average value per withdrawal rises (line trends up) while total value falls modestly.
Text takeaways: By 2028 annual number of cash withdrawals falls to **135 million**, an **18% drop** vs 2022. Average usage stays just over **2,100 withdrawals per machine per month**. Total value of withdrawals in 2028 forecast at **CHF 61 billion (USD 64 billion at 2022 FX)**, **3% lower than 2022**. Average withdrawal value rises as customers visit less but withdraw more. Sources: Swiss ATM deployers, SNB and RBR analysis.
