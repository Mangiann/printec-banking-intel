# ISO 20022 Migration — Regulation Findings (2026-07-14)

Workstream: ISO 20022 migration. Focus: deadlines for high-value (RTGS) + instant rails per market, Printec 17-country footprint.

## Headline NEW discovery this run
**BIS CPMI Payments Interoperability & Extension (PIE) Task Force — Task Team 3 "Fostering ISO 20022 harmonisation" follow-up report, February 2026** (https://www.bis.org/cpmi/pietf/iso20022_2026.pdf). Bilateral engagement with RTGS operators gives per-country ISO 20022 alignment status + timelines. Global harmonisation target: **end-2027**. This report is the primary source for the per-market rows below and was NOT seen by the 2026-06-24 baseline.

## Key per-market status (footprint)
- **Czech Republic (CZ)** — CERTIS RTGS runs on a PROPRIETARY standard and has **NO plans to migrate to ISO 20022** (cites future euro adoption / eventual T2 migration; domestic ISO build seen as disproportionate). => No domestic RTGS ISO project in Czechia; Czech banks face only cross-border CBPR+ Nov-2026. NEW.
- **Hungary (HU)** — VIBER migrated to ISO 20022 end-**October 2025** (Swift IAP v.2). Post-migration stabilisation ongoing. Hybrid postal address NOT yet supported (no confirmed timeline); external code-set full alignment pending future base upgrade. NEW detail.
- **Romania (RO)** — ReGIS (NBR). Fully-unstructured postal address option to be **removed in the 2026 release**; base-message upgrade to ISO MR2025 planned **Nov-2027**. NEW detail.
- **Albania (AL)** — AIPS RTGS adopting ISO 20022 (HVPS+ aligned); hybrid postal address alignment via IAP upgrade **Nov-2027**; base upgrade Nov-2027. NEW.
- **Ukraine (UA)** — SEP 4.0 on ISO 20022 since 01/04/2023 (24/7). Partially aligned: does NOT support <InstructedAmount>/<ExchangeRate>/<ChargesInformation>; time-format & restrictive postal-address gaps; base upgrade planned **Nov-2027**. NEW detail vs baseline (SEP 4.1).
- **Euro-area footprint (AT, CY, GR, SI, SK, HR)** — T2/Euro1 on ISO 20022 since Mar-2023. Unstructured postal address removal **Nov-2026**; ISO message unfreeze: **T2 R2026.JUN → ISO MR2024**, **T2 R2026.NOV → ISO MR2025** (7 core RTGS pacs/camt messages excepted). NEW detail.
- **Serbia (RS)** — NBS RTGS/ACH ISO 20022 migration complete Nov-2025 [STANDING].

## Cross-cutting deadline
- **SWIFT CBPR+ 14/11/2026**: unstructured postal addresses removed network-wide; only fully-structured or hybrid (Town+Country mandatory) accepted, else NAK/reject. Post-Nov-2025 CBPR+ adoption ~97%; but ~65% of messages still carried unstructured addresses as of Mar-2026; ~65 market infrastructures had no alignment plan. Affects correspondent-banking traffic of ALL 17 footprint markets. (Confirmed vs baseline; stats deepened.)

## Printec mapping
ISO 20022 core/RTGS migration is chiefly a core-banking / payment-hub job (not Printec's core), so direct opportunity is modest. Strongest angles: (1) **IMTF Siron / FICO AML sanctions screening** — structured Town+Country address data (Nov-2026 mandate) materially improves screening precision and false-positive rates; sell screening tuning/re-config. (2) **INETCO transaction monitoring** — must parse richer pacs.008/pacs.004 payloads; monitoring re-instrumentation. ATM/POS card rails (ISO 8583) largely unaffected => low relevance for NCR/x-core/Verifone lines.
