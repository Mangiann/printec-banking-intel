## Method breakthrough
`clarity-project.info/tender/<friendlyID>` is server-rendered HTML and resolves the friendly ID to the Prozorro UUID **and** to the winner, bidder EDRPOU codes, values and dates — no browser, no CDB UUID needed. Prozorro's own search API works as `POST prozorro.gov.ua/api/search/tenders` with body `{"text":"...","page":1}` (page is 1-based; `query`/`tenderID` keys are ignored).
