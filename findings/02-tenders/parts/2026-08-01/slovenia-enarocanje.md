ACCESS ROUTE (new, reusable): enarocanje.si is a Vue single-page app - /pregled-objav/<id> returns HTTP 404 to any plain fetcher even though it is the correct human-facing URL. The working route is the site's own JSON API at https://www.enarocanje.si/api/ (no auth, no cookie, plain desktop User-Agent): POST obrazec/objava/obrazecGetGrid searches notices (filters narocnikMaticna exact, naslov accepts SQL LIKE wildcards e.g. %bankovc%, idSifCpv with podrejeniCpv, objavaDejanskaDatumOd/Do, startRow/endRow); GET obrazec/objava/obrazecGet?id= returns the full structured notice including lots (obrazecSklop), award records (obrazecOddaja with winner name + registration number + bid counts + values) and contracts (obrazecPogodba); GET obrazec/objava/dosjeObrazecGetList?idDosje= lists every document in a procedure dossier, which is how open/awarded/cancelled status was verified; GET sifObrazec/sifCpvGetList?aktivnost=true returns the CPV tree with the internal ids the grid needs. Decision (ODL) notices expose a signed PDF at api/datoteka/get?id=<base64> that names the winner WEEKS BEFORE the formal award notice - that is how the Banka Slovenije PKI and MNZ POS winners were captured; PDFs were text-extracted locally with pdfminer.six.
