## Access
nbrm.mk returns HTTP 403 (Cloudflare 'Just a moment' JS challenge) to BOTH WebFetch and desktop-UA curl, on HTML pages AND on direct /content/*.xlsx and /content/*.pdf paths - the documented desktop-UA workaround does NOT work here. Also blocked: r.jina.ai proxy (returns the Cloudflare interstitial). WORKING ROUTE: open nbrm.mk in a real browser (Claude browser pane / preview_start), let the JS challenge auto-solve, then use in-page fetch() on the /content/... path - same-origin requests carry the cf_clearance cookie and return HTTP 200. The cookie is httpOnly so it cannot be exported to curl, and blob-download did not land a file on the local filesystem, so binary files must be handled inside the page. For PDFs I inflated the FlateDecode streams in-page with DecompressionStream('deflate') and pulled the text operators - this works for numbers but NOT for Cyrillic labels (custom font encoding, no usable ToUnicode). NEW ROUTE DISCOVERED: nbstat.nbrm.mk/pxweb/mk/ returns 200 to plain desktop-UA curl (Cloudflare does not cover this host), exposing the NBStat statistical portal with the 'MS i KS' (monetary + interest-rate statistics), 'Eksterni statistiki' and 'Finansiski smetki' databases. However nbstat.nbrm.mk/ root is 403 and there is no PxWeb REST API (/pxweb/api/v1/... errors); navigation requires ASP.NET __VIEWSTATE postbacks. Payment statistics are NOT in NBStat. Blocked and abandoned: https://www.nbrm.mk/ns-newsarticle-soopstenie-monetarni-dvizenja-juli-2026.nspx (403, guessed slug).

GAP NOT CLOSED: the absolute CASH-IN-CIRCULATION series. NBRSM publishes monetary aggregates only through the NBStat PxWeb portal (nbstat.nbrm.mk/pxweb/mk/ - reachable, but an old ASP.NET postback UI with no REST API) and through a monthly press-release PDF. I did extract the Jul-2026 monetary press-release PDF's numeric grid, but its Cyrillic row labels use a custom font encoding that does not map to Unicode, so the rows cannot be attributed to a metric - and per the hard rules I will not guess which row is currency in circulation. No currency-in-circulation figure is therefore reported. Cash TREND is instead reported from primary ATM flow data (Table 5): ATM withdrawal value +11.8% y/y while ATM deposit value +53.0% y/y at Mar-2026.
